## 2. 用户目标与场景

### 2.1 核心用户故事

1. 作为下载大文件/跑长任务的用户，我合上笔记本盖子放进包里后，电脑仍然运行，任务不中断。
2. 作为远程办公用户，我希望合盖或离开工位时 Teams/Slack 不把我标记为 Away（可选的输入活动模拟）。
3. 作为演示/监控用户，我希望屏幕常亮，电脑不休眠。
4. 作为夜间任务用户，我希望设置 8 小时或无限时长的保护，并在结束后自动恢复正常睡眠策略。
5. 作为在意隐私的用户，我希望应用完全离线，不收集、不上传任何数据。
6. 作为 Windows 用户，我习惯通过托盘图标的右键菜单快速操作，不希望应用占用任务栏。

### 2.2 Windows 交互映射（用户明确要求）

> “在苹果的顶部栏，它是可以点击、可以交互的，但 Windows 不行，所以你就隐藏那个图标，我们把所有的点击、长按的功能搬到右键那个隐藏的图标里面。”

解释与落实：

- “隐藏那个图标”落实为 **Windows 任务栏/Dock 等价物隐藏**：主窗口 `skipTaskbar`，应用纯托盘运行，不出现任务栏按钮。
- 托盘图标放在通知区域（可能被 Windows 收进溢出区，即“隐藏的图标”）。
- **右键菜单是功能完备的一等公民**：开关、时长、显示模式、高级模式、合盖保护、设置、关于、退出全部可在右键菜单完成。
- 左键点击托盘图标作为可关闭的 Windows 习惯增强：默认打开控制面板（与 macOS 点开菜单栏 popover 对应）。
- macOS 上的“左键/右键切换”在 Windows 不照搬；所有切换动作都进入右键菜单，避免误触。
- 面板内的“长按状态环打开设置”作为键盘/鼠标高级手势保留，但不作为唯一入口。

## 6. 关键约束与风险

1. **合盖策略写入需要管理员权限**：Windows 不允许普通进程修改当前电源方案的 LIDACTION。方案：一次性 UAC 启动常驻 helper；用户拒绝时明确降级。
2. **Modern Standby（S0）机型差异**：本机为联想笔记本、Windows 10 19045、S0 低电量待机；`powercfg /q` 默认不显示 LIDACTION（注册表中存在但隐藏）。helper 直接通过 Power API 读写，绕过显示层差异；真机合盖行为需用户实测。当前开发环境无管理员权限，无法完成真实写入验证，验收文档会如实标注。
3. **合盖策略是全局系统设置**：异常退出可能留下 “Do nothing”。必须实现 helper 自恢复、启动残留检测、正常退出恢复、系统关机恢复四层兜底。
4. **输入模拟可能点亮屏幕**：F15 只重置空闲计时，但 Windows 可能将其视为输入。高级模式默认关闭，并在 UI 中说明。
5. **托盘图标可能进入溢出区**：这是用户要求的“隐藏图标”形态；右键菜单仍是完整入口，同时保留左键面板与全局快捷键。
6. **版权与商标**：本项目是独立移植/致敬实现，不隶属于原作者；UI 采用相同设计语言，但图标与素材自绘，关于页明确声明。
