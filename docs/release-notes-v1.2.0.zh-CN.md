# InsomniaZ for Windows 1.2.0

> 2026-11-07 · Windows 10 22H2 / Windows 11 · x64
> English: [release-notes-v1.2.0.md](release-notes-v1.2.0.md)

macOS 菜单栏应用 **InsomniaZ – Never Sleep** 的独立 Windows 移植版。1.2.0 保留 1.0.0 / 1.1.0 的全部能力——防休眠、合盖保护、显示模式、定时会话、低电量保护、软叫停（Soft Stop）、托盘交互与双语界面——并新增 **Autopilot（自动投递）**：在后台按计划把完整提示词送进桌面 AI 聊天应用。

**与原作者无关联，未包含原应用受版权保护的素材。**

> **发布状态：已准备，未发布。** 1.2.0 的安装包尚未构建，另有两道验证闸门未完成（见「验证」）。本仓库没有任何内容被推送到 GitHub。

## 1.2.0 新增

### Autopilot — 定时提示词投递

- **真正的原生窗口**：可自由缩放、最小化、最大化、全屏，有任务栏条目。关闭或最小化只是隐藏，调度器继续运行；关闭设置窗口会回到主控制面板。
- **任意计划**：手动、单次、每天、每周（带星期几选择器），或每 N 分钟（1…10080）；另有补跑策略（`补跑一次` / `跳过`），受可配置的补跑窗口约束。
- **每任务独立的模型、思考强度与参数**：思考强度五档环（关闭/低/中/高/最高），在 ZCode 中用 `Ctrl+T` 单步切换并回读确认；temperature / top-p / max-tokens 原样透传。
- **不做预选**：目标应用无需处于前台；除非任务里明确写了，Autopilot 不会替你挑模型或会话。
- **实时目录与会话同步**，与内置种子目录合并。ZCode 因额度耗尽而隐藏模型时，会先刷新模型列表再选择。
- **三级控件定位**：MSAA 名称/角色 → OCR 标签 → 窗口相对比例锚点。用的是比例而不是屏幕像素，因此窗口没最大化、多显示器或 DPI 变化都能工作。WorkBuddy 的无障碍树几乎为空，改用 `PrintWindow` + WinRT OCR 读取。
- **附件**：路径校验、移动后搜索、可选备份（带配额与保留策略），以及**原路径优先规则**——备份会先复原回原目录，*再*让目标应用读原路径。缺失或超限的文件会被跳过并在提示词末尾追加说明，而不是让整次投递失败。
- **内置错误目录**：约 50 个错误码，各自带尝试上限、退避与终止动作（兜底 / 推迟 / 下一候选 / 继续 / 失败 / 阻塞）。每次运行最多点两次发送键；仍未确认成功则以 `DUPLICATE_RISK` 失败并阻塞该任务，绝不冒重复发帖的风险。
- **应急兜底**：先本地 Ollama（`/api/chat`，永不携带 `Authorization` 头），再 OpenAI 兼容端点——后者**默认关闭**，需要显式开启且已存密钥。每通道 3 次尝试、平方退避、60 秒超时。没有密钥时以 `FALLBACK_NO_KEY` 失败，不会去调用付费 API。
- **保护闸门**：检测到录屏、远程控制或 CPU 超过阈值时，Autopilot 窗口彻底隐藏并推迟 GUI 投递，20 秒冷却、5 分钟保持。没有启用的 GUI 任务时完全不探测。
- **自适应实时保存**：基准 500 ms，负载升高时拉长（绝不超过 15 秒）；原子写入；损坏文件保留而不删除；休眠与关机前落盘。
- **六个页签**：任务、运行、模型、会话、附件、设置，全部中英双语。

### 修复

- **附件解析不再让同名文件顶替你自己的备份。** 现在先把备份复原回原目录再搜索，并且对已知文件只在大小或 SHA-256 一致时才接受候选。此前 Documents 目录里一个无关的 `NOTES.md` 可能被当作缺失的 `notes.md` 投递出去。
- **自动化 helper 现在能用系统自带的 .NET 4.8 编译器编译。** 前台锁路径里的 `out _`（C# 7）被 `csc.exe` 拒绝，改为显式 out 变量。
- **每周任务真正遵守选中的星期几。** 编辑器原先没有星期几选择器，导致每周任务每天都触发。
- **保护芯片显示真实原因**——被接管 / 高负载——而不是永远写「正在录屏」。
- **界面限额与契约对齐**：提示词长度 200 000（编辑器原先截到 32 000）、尝试上限 60（输入框原先只到 10）、CPU 阈值 0.3…0.99 且默认 0.75（输入框原先允许 0.05…1 并静默重新夹紧）。
- **「新任务的默认尝试上限」现在真的生效**——新任务继承设置里的值，而不是硬编码 3。
- **补跑策略暴露到编辑器**（`补跑一次` / `跳过`）。

### 文档

- 所有面向用户的文档现在都有**英文与中文**两版：README、SECURITY、Autopilot 与软叫停指南、发布清单，以及本发布说明。
- 历史设计、验收与评审记录、实现前的 Autopilot 设计稿，以及 1.0.0 / 1.1.0 发布说明，已移入 [`design-archive/`](../design-archive/README.md)。原始桌面侦察 dump 只留在本地并已 gitignore——其中含个人窗口标题与路径，永不发布。

## 安装与升级

1. 优先安装版；不想安装就直接运行便携版。覆盖安装 1.0.0 / 1.1.0 会保留设置与会话数据。
2. 校验 SHA-256。二进制未签名，SmartScreen 可能提示未知发布者；确认校验和后选择「更多信息 → 仍要运行」。
3. 完成三步引导，之后应用只在托盘运行。
4. 软叫停默认关闭；Autopilot 的远程兜底与附件备份同样默认关闭。
5. **第一次定时投递之前**：自己先启动目标应用、让窗口可见、同步模型，然后完整看一次「立即运行」。Autopilot 没有 dry-run、没有白名单——它真的会点发送。
6. 开启合盖保护会弹一次 UAC；拒绝后其余防睡眠功能仍可用。

没有自动更新。卸载会保留 `%APPDATA%\InsomniaZ\`（设置、日志、软叫停与 Autopilot 数据）；要彻底清理请手动删除该目录。

## 已知限制

- **Autopilot 没有 dry-run、白名单或确认闸门。** 它真的会点击；目标应用必须已在运行且窗口可见，程序不会自动拉起它。
- **兜底回复不会回传**给目标应用，也不保存。图片只在 Ollama 通道以 base64 内联，远程 API 通道会丢弃。
- **GUI 自动化依赖目标应用的无障碍与布局。** 纯 Canvas 界面无法读取；目标应用改版可能破坏比例锚点与 OCR 标签；以管理员运行的目标需要同等级权限。
- **保护性休眠与物理合盖仍未在真机验证。**
- **未签名二进制**、Windows 11 / OEM 电源方案、通知视觉、安装版开机启动，以及全新系统的 NSIS 安装/卸载，仍需按机器逐项确认。
- **内存**空闲约 213 MB，高于 160 MB 设计目标；空闲 CPU 0–0.16%。
