## 安装与升级

1. 优先安装版；不想安装就直接运行便携版。覆盖安装 1.0.0 / 1.1.0 会保留设置与会话数据。
2. 校验 SHA-256。二进制未签名，SmartScreen 可能提示未知发布者；确认校验和后选择
   「更多信息 → 仍要运行」。
3. 完成三步引导，之后应用只在托盘运行。
4. 软叫停默认关闭；远程端点需要显式开启。
5. 开启合盖保护会弹一次 UAC；拒绝后其余防睡眠功能仍可用。

没有自动更新。卸载会保留 `%APPDATA%\InsomniaZ\`（设置、日志与软叫停数据）；
要彻底清理请手动删除该目录。

## 已知限制

- **保护性休眠与物理合盖仍未在真机验证。**
- **未签名二进制**、Windows 11 / OEM 电源方案、通知视觉、安装版开机启动，以及全新系统的
  NSIS 安装/卸载，仍需按机器逐项确认。
- **内存**空闲约 213 MB，高于 160 MB 设计目标；空闲 CPU 0–0.16%。持续满载压测时进程树内存升到约 486 MB，随后保持稳定。
- **GUI 识别依赖目标应用的无障碍与布局**——纯 Canvas 界面无法读取，目标应用改版可能破坏
  比例锚点与 OCR 标签。
