# InsomniaZ for Windows 1.0.0

> 2026-10-31 · Windows 10 22H2 / Windows 11 · x64

这是 macOS 菜单栏应用 **InsomniaZ – Never Sleep** 的独立 Windows 移植版。首个公开版本保留原应用的核心能力与主要界面：合盖继续运行、显示常亮/自动、定时会话、高级活动模拟、低电量保护、全局快捷键、双语与主题切换，并把原菜单栏的点击/长按交互完整搬进托盘。

## 亮点

- **合盖继续运行**：临时把当前电源方案的合盖动作改为“不采取任何操作”（AC/DC），写入前备份、写入后回读、失败回滚；退出或崩溃时自动还原，异常重启后下次启动提示恢复。
- **三层唤醒保障**：Electron `powerSaveBlocker` + 提权助手 `SetThreadExecutionState` + 合盖策略；退出/崩溃自动还原，异常重启后提示恢复。
- **显示模式**：`On` 屏幕常亮；`Auto` 屏幕可关闭、系统继续运行。
- **定时会话**：15m / 30m / 1h / 2h / 4h / 8h / ∞，支持异常退出后恢复未到期会话。
- **高级模式**：定期发送无害 F15 按键，避免被 Teams/Slack 判定为空闲。
- **低电量保护**：默认 20%，可配置 5–95%，可设置使用电池时停止。
- **托盘完整菜单**：开关、时长、显示、合盖、活动模拟、面板、设置、关于、兼容性检查、退出。
- **中英双语 / 深色、浅色、跟随系统 / 紧凑布局 / 通知开关**。
- **零网络、零遥测、无自动更新**。

## 安装

1. 优先选择安装版；不想安装时直接运行便携版。
2. 校验 SHA-256。安装包未签名，SmartScreen 可能提示未知发布者；确认校验和后可选择“更多信息 → 仍要运行”。
3. 首次启动完成三步引导，应用转入托盘。
4. 左键托盘图标打开面板，右键打开完整菜单；关闭窗口只是隐藏，退出请用“退出”。
5. 开启“合盖后保持运行”时会出现一次 UAC；拒绝后其余防睡眠功能仍可用。

安装版会创建开始菜单与桌面快捷方式；卸载后 `%APPDATA%\InsomniaZ\` 中的设置与日志会保留，需要彻底清理时手动删除该目录。本版没有自动更新，请手动下载新版本覆盖安装。

## 已知限制

- **物理合盖与合盖状态拔插电源未实测**：策略写入/恢复已走通，但“合上盖子任务不中断”仍需在目标机器上手工确认。
- **未签名**：SmartScreen 会提示未知发布者。
- **Windows 11 / 不同 OEM 电源方案未逐一覆盖**；Modern Standby 与多显示器为尽力适配。
- **通知视觉未人工确认**：是否展示、是否被专注助手拦截取决于系统策略。
- **安装版开机启动未做重启验证**；便携版不支持开机启动。
- **NSIS 安装/卸载流程未在全新系统实测**：安装包由已验收的 `win-unpacked` 目录生成，安装向导本身仍建议在目标机器上走一遍。
- **内存约 213 MB**（应用 186 MB + helper 27 MB），高于 160 MB 设计目标；空闲 CPU 0–0.16%。
- **UI 复刻边界**：官方仅提供 5 张商店截图，设置页、引导页与部分状态为同设计语言的合理推断。
